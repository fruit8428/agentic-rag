# 子計劃 9c：前端加入社與管理介面

**複雜度：⚠️ 中等**（1 個新頁、1 個新分頁、2 個既有元件修改）
前置：9b 完成。

## 任務 1：登入後先取得社別（`App.tsx`）
- 登入後呼叫 `GET /api/clubs/me`，存 `{clubId, clubName, role}`。
- `clubId` 為空 → 只渲染 `JoinClubPage`，不顯示聊天/文件分頁。
- 頂部導覽列顯示「🏷 {clubName}」；role 為 admin 時多一個「管理」分頁。
- 把頂部的「模組 8：子代理…」課程標籤改成「扶輪社 3523 地區知識庫」。

**驗證**：無社帳號登入只看到加入頁；加入後自動切到聊天頁並顯示社名。

## 任務 2：加入社頁（新檔 `components/JoinClubPage.tsx`）
- 下拉選社（`GET /api/clubs`）＋ 社內密碼輸入 ＋「加入」按鈕。
- 錯誤顯示「社內密碼錯誤，請向貴社執秘確認」。
- 說明文字：「加入後可查閱地區公開資料與貴社社內資料」。
- 手機寬度可用（單欄、按鈕全寬）。

**驗證**：錯密碼顯示錯誤不跳頁；對密碼進入主畫面。

## 任務 3：文件導入頁加上範圍（`components/IngestView.tsx`）
- 上傳區加「文件範圍」選項：`社內（{clubName}）` 預設；admin 多一個 `地區公開`。
- 文件列表每筆顯示徽章：`🌐 地區公開` 或 `🔒 {club_name} 社內`。
- 刪除按鈕：上傳者本人或 admin 才顯示。
- 把課程用的「模組 3/5 實驗室」區塊預設收合（保留功能，不干擾實際使用）。

**驗證**：member 上傳 → 列表顯示社內徽章；admin 選地區上傳 → 地區徽章；用另一社帳號登入看不到前者。

## 任務 4：聊天頁來源徽章（`components/ChatView.tsx`）
- 檢索來源卡片標題旁加 `🌐 地區` / `🔒 社內` 小徽章（後端來源物件已帶 `scope`）。
- 範例提問按鈕文字改成貼近扶輪社用法（保留原有四種能力的示範）。

**驗證**：問地區級文件問題時來源顯示地區徽章。

## 任務 5：管理分頁（新檔 `components/AdminView.tsx`，僅 admin 可見）
- **社管理**：表格（社名、社友數、文件數）＋「新增社」表單（社名、初始密碼）＋「重設密碼」＋「刪除」（刪除前 confirm，用自訂對話框而非 `window.confirm`）。
- **社友管理**：表格（email、社別、角色）＋「重新指派社」下拉。
- 所有錯誤（409 有社友不能刪等）以紅色提示顯示後端 `detail`。

**驗證**：新增社後立即出現在加入頁的下拉；刪除有社友的社顯示「尚有 N 位社友」錯誤。

## 任務 6：社設定（放在頂部使用者選單或管理分頁旁）
- 「變更本社密碼」小表單：舊密碼、新密碼、確認新密碼 → `POST /api/clubs/me/password`。

**驗證**：改密碼後用舊密碼加入 → 401；新密碼 → 200。

## 任務 7：建置、部署、線上驗證
- `npx tsc --noEmit` 零錯誤、`npm run build` 成功。
- commit + push → Vercel 自動部署（正式環境部署前先向使用者確認）。
- 線上用兩個測試帳號重跑計劃 9 總覽的端到端驗證；手機寬度（375px）檢查加入頁與聊天頁。
- 更新 `PROGRESS.md`：新增「模組 9：地區與社內權限分級」五項打勾。
