# 子計劃 9a：資料庫結構與 RLS

**複雜度：✅ 簡單**（一個 SQL 遷移檔，一次執行）
前置：無。產出：`supabase/migrations/009_module9_clubs_and_scopes.sql`

## 任務 1：建立 clubs 與 profiles 表
```sql
create table public.clubs (
  id uuid primary key default gen_random_uuid(),
  name text not null unique,
  password_hash text not null,
  created_at timestamptz default now()
);
create table public.profiles (
  user_id uuid primary key references auth.users(id) on delete cascade,
  club_id uuid references public.clubs(id),
  role text not null default 'member' check (role in ('member','admin')),
  joined_at timestamptz
);
```
- 新使用者註冊時自動建立 profiles 列：trigger `on auth.users insert → insert profiles(user_id)`。
- 回填：對現有 auth.users 每人補一列 profiles。
- 把 fruit8428@gmail.com 設為 `role='admin'`。

**驗證**：`select count(*) from profiles` = auth.users 人數；fruit8428 的 role 為 admin。

## 任務 2：documents 加上 scope 與 club_id
```sql
alter table public.documents
  add column scope text not null default 'club' check (scope in ('district','club')),
  add column club_id uuid references public.clubs(id);
alter table public.documents add constraint documents_scope_club_chk
  check ((scope = 'district' and club_id is null) or (scope = 'club' and club_id is not null));
```
- 回填：現有全部文件 `update documents set scope='district', club_id=null`（使用者確認兩份都是地區級）。注意先 update 再加 constraint，避免既有列違反。
- 索引：`(scope, club_id)`。

**驗證**：`select filename, scope, club_id from documents` 兩筆皆為 district / null。

## 任務 3：輔助函數與 RLS
```sql
create or replace function public.current_club_id() returns uuid
language sql stable security definer as $$
  select club_id from public.profiles where user_id = auth.uid()
$$;
create or replace function public.is_admin() returns boolean
language sql stable security definer as $$
  select coalesce((select role = 'admin' from public.profiles where user_id = auth.uid()), false)
$$;
```
- **clubs**：所有登入者可 `select id, name`（加入社時要選社）；但 `password_hash` 不能被讀 → 做法：建 view `clubs_public (id, name)` 給前端，`clubs` 表本身只允許 admin select/insert/update/delete。
- **profiles**：本人可 select 自己；admin 可 select/update 全部；insert 由 trigger（security definer）處理。
- **documents**：移除舊的 `auth.uid() = user_id` select policy，改為
  `using (scope = 'district' or club_id = public.current_club_id() or public.is_admin())`。
  insert：`with check (auth.uid() = user_id and ((scope='club' and club_id = public.current_club_id()) or (scope='district' and public.is_admin())))`。
  delete：`using (auth.uid() = user_id or public.is_admin())`。
- **document_chunks**：select policy 改為 `exists (select 1 from documents d where d.id = document_id and (d.scope='district' or d.club_id = public.current_club_id() or public.is_admin()))`。
- Storage bucket `documents`：後端用 service role 上傳/刪除，不需改。

**驗證**（用 anon key + 使用者 JWT 直接查 REST）：
- 使用者未加入社：`GET /rest/v1/documents` 只回 district 文件。
- 使用者加入甲社後：回 district + 甲社文件，不含乙社文件。
